# SFT shortcut 审计：事后探索性结果

**结论：新模型有明显的扫描开局模板化，但现有结果不能被“只学会 finish”“固定类别/坐标先验”或“整张训练地图直接复述”充分解释。它确实输出了与当前世界相匹配的类别—位置组合；证据尚不足以把这种世界特异性归因为完整的视觉三维推理，更不能证明自适应探索或未见资产泛化。** 本目录全部分析是评测结束后设计的探索性诊断，不修改原封存确认分析，不产生新的确认性 p 值或置信区间，没有任何模型调用、训练更新或服务启动。

## 证据与复算

- 覆盖原 128 父世界、5 组结果、640 状态；575 完成预测、65 失败计零。独立最大基数类别/距离二部匹配精确复现 0.75m/0.25m 两档共 1,280 个 F1，并验证全部状态哈希。
- 另外核验 575 预测文件、512 个场景文件的原封存哈希。只读 SSH 提取了冻结训练 JSONL 的最后 finish 地图、动作，以及 838 训练世界的小型 GT/pose/asset 元数据，没有下载训练图像。实际 train.jsonl SHA256 为 `bd4469d6ba66715c4a62e5791d17c7eb2ef5e37da24a8bd0c8226cae20d59ebd`；838 个 finish 地图与原来源预测相同，838 训练世界哈希与旧世界排除快照相同。
- 所有对象得分使用原 `start_camera_xy` 米制坐标。独立从世界 x/z 与 start[x,z,yaw] 重建训练/测试共 5,940 个 GT 位置，最大误差 1.99e-15m。没有把不同相机坐标误当同一房间坐标。
- 原始独立确认仍为：e2e new/base/full128 = 0.724847/0.177096/0.554568；相同固定公共扫描的 reader new/base = 0.643361/0.209957。以下结果不替换这些确认结果。

## 支持什么、削弱什么、仍未排除什么

### 1. 支持：强烈的固定扫描开局；但整条轨迹不是完全固定

新模型 127/128 世界（99.22%）的首个请求动作都是连续三次 `+90°、0m`，其余 1 个是三次 `−90°、0m`。冻结训练中前一模板为 593/838（70.76%）。新模型前两次请求共 16 种、完整 acquisition 请求序列共 91 种；base 的首动作有 25 种，full128 有 3 种。

这支持新模型强化了一个实用的固定全景扫描习惯，不能直接把 e2e 提升称为“学会场景依赖的主动探索”。也不能因为动作多样性降低就认定有害：本任务的未知单间使全景扫描通常合理。这里统计的是生成的请求动作，包括可能被拒绝的请求，去掉解释/理由并正规化数值；并不是已执行轨迹一致性的证明。第二步以后的多样性也不能单独证明视觉条件化。

相同 16 帧公共扫描 reader 的 new 仍明显优于 base，说明总体收益不能只由新模型多采帧/扫描模板解释。但这不是 acquisition 与 readout 的因果分解；需要交叉固定动作、固定读图器才能分开。

### 2. 削弱：只有 finish 或格式改善

作一个故意偏袒基线的算术上界：把 base 的 33 个 e2e 失败全部填成完美 F1=1，new 的平均优势仍为 +0.28994；把 full128 的 5 个失败全部填满，new 优势仍为 +0.13122。reader 同样把 base 的 27 个失败填满后仍有 +0.22247。

这是保守敏感性算术，不是实际格式修复实验或因果贡献比例。new−base 原 +0.54775 中，在 base 已完成的 95 个世界上的改善对全样本均值贡献 +0.35714；在 base 失败世界上的贡献 +0.19061。不能把后者全都称为“格式收益”，因为对应世界的定位/类别能力可能也改变。

### 3. 削弱：一张通用地图、家族坐标模板或单热点先验就能得高分

以下均为**保存输出的离线评分扰动，绝不是删图、错图或去视觉模型实验**。每项保留全 128 个目标父世界，失败预测为空图计零。分层权重仍为 96/128 和 32/128。

- 直接把 new e2e 保存地图换到另一世界，穷举 16,256 个 source→target 异世界有序对、先在每个 target 内对 donor 均匀平均，再对 target 平均：F1 **0.00874**。同普通/物理遮挡层 10,112 对：**0.01110**；同层且同布局家族 2,048 对：**0.01149**。原图为 **0.72485**。
- 额外提供 source/target 的私有真实相机姿态和房间尺寸，先还原房间坐标、按两边房间尺寸线性缩放再换到目标相机坐标。同层同家族交换为 **0.02192**；reader 对应为 **0.02220**。这是刻意给地图模板有利条件的元数据 oracle；目标模型实际看不到这些私有量。
- 真正只从训练统计拟合的固定无图基线：对冻结 838 个监督 finish 地图，在 0.25m 网格选每类的 0.75m 命中热点；按训练世界命中率排序，并只在训练输出上选择使平均 F1 最高的前 k 类，得到固定 10 对象地图。测试 F1 **0.01585**。不使用测试 GT 拟合或选择。该基线很受限：每类仅一个热点、没有复杂类别共现或多模态布局，因此低分不能排除所有先验。
- 允许看见测试世界的私有 family 标签，使用各家族训练输出分别拟合上述先验，F1 **0.01453**。这是 family 元数据 oracle，不能冒充可部署无图模型。
- 保留 new 原预测的类别与对象数、把每类位置替换为训练热点，e2e F1 **0.02542**，reader **0.02342**。这里仍保留模型已看图得到的类别信息，不能称无图基线。
- 在同一世界内保留所有预测坐标和类别多重集合，仅均匀打乱类别—坐标配对，每父世界 200 次、离线统计置换 RNG seed 20260921（只控制离线排列，并非第二训练 seed；唯一训练 seed 仍为 20260920；含恒等排列及重复类别）：e2e **0.16092**、reader **0.15089**。因此成绩不只依靠猜对房间类别与一团大致合理的坐标，也依赖它们之间的对应关系。

这些结果证明保存输出对当前世界的精确对应关系很重要，削弱了几个具体、简单的 shortcut。它们**不证明模型真实依赖 RGB**：输出可能仍由图像中的易学线索、已知资产几何、公开相机参数、project_ground 工具、场景共现或未测试的先验共同产生。

### 4. 削弱：整张训练地图的直接记忆复述；仍未排除局部/变形记忆

new 的 128 份 e2e 与 128 份 reader 地图中，与任一训练 finish 地图类别/坐标完全相同的数量均为 **0**（忽略顺序、ID、evidence，坐标正规化到 1e-6）。

再给“记忆检索”极大的事后优势：让测试 GT 为每个测试世界从 838 个训练地图中挑出得分最高的一张，原相机坐标直接复述的均值也只有 **0.27059**。进一步利用真实私有相机姿态与房间尺寸，把每张训练地图还原房间坐标、归一化缩放并试遍 8 个 D4 旋转/镜像，穷举 **858,112** 个候选地图变换，GT 选最优后的均值为 **0.42261**；限制相同家族则为 **0.36167**。没有任何测试世界满分，单世界最高 0.66667。

这不是可部署基线，也不是模型输出的生成机制证据：选择步骤偷看了测试 GT，且用了私有 pose/尺寸。即便如此，整图＋这组简单变换仍明显不足以复制实际收益。它不能排除记忆局部资产、组合训练片段、每对象调整、复杂非线性变形或更强检索生成。

### 5. 尚未排除：已知资产、同体系布局、工具依赖与同 seed 特化

训练与评测都是相同 **14/14 个资产定义**、相同 **8/8 个布局家族**；训练/测试 scene ID 交集为零。已有 split 审计对 4,428 个旧世界及相互新世界排除了类别一一匹配、D4 等价的近重复几何：房间尺寸同时满足 0.5m 与 8% 容差、全部对象位置距离≤0.35m 才判重复；忽略材质、ID、资产 yaw/scale。这里核验了训练世界与该排除快照的字节一致性，**没有重新跑 4,428 世界的几何算法**。

因此没有发现这一定义下的训练测试泄漏或整图抄写迹象，但新资产、真实图像、新生成器、不寻常相机参数、超出训练尺度等泛化均未建立。固定初始相机高度、投影参数与共享资产说明可能让问题大幅简化；工具 project_ground 的贡献也未被控制。单训练 seed 仍是原有边界。

隐藏目标 `observed=false` 只表示每帧均未达 **263 分割像素**，不等于零可见像素。`matched=true, observed=false` 必须结合原始分割像素数和模型 evidence 帧解释，不能据此认定盲猜、泄漏或作弊。

## 下一步最小预登记干预建议（本次未执行）

1. **先检验真实 RGB 依赖。** 封存 32 个新父世界（24 普通、8 物理遮挡；普通 8 家族各 3 个），固定 scanner、模型、预算、提示词和对象 F1，给 new 和 base 各跑原图与同层/同家族世界的整套 RGB 错配。预先确定无固定点 donor 置换；一个父世界是配对单位，失败计零。把 new 的“原图−错图”作为单一主干预对比，base 交互为描述性诊断。除 recipient GT 外，预先报告 donor GT 得分以确认输出是否跟随 donor 图像。32 世界是最小机制 pilot；精确效应及泛化仍需扩大样本。可加入空白图作为 OOD 辅助条件，但不能仅用空白图下降证明视觉理解。
2. **再区分探索与读图。** 对同一组新世界固定 new 读图器，比较一个预先封存的“3×90°扫描＋固定移动”策略与 new 自选动作，强制相同 RGB/调用预算；不要从已见结果挑最优脚本。主指标是父世界 F1，次指标是隐藏目标连续像素覆盖、路径长度与碰撞。这才检验自适应选择的增益。
3. **再检验坐标与资产 shortcut。** 用相机 pose/receipt 一致的整组旋转/镜像或初始朝向变化，预登记坐标等变误差；另用持出资产网格/几何、不同布局生成器测试。真变换时必须同步 RGB 与 receipts/GT；单纯改坐标提示容易成为格式分布外测试。分阶段新增一个主假设，避免把多项事后“最有效干预”选成确认结论。

## 可复算文件

- `collect_training.py`：可选的只读远端小数据采集；`training_metadata.json` 是本次冻结派生输入（约 4.1MB）。
- `verify_sources.py` / `source_verification.json`：575 预测、512 场景、838 训练世界/地图的封存来源复核。
- `analyze_shortcuts.py` / `shortcut_analysis.json`：主离线审计、每世界交换得分、完整方法说明。
- `aligned_training_oracle.py` / `aligned_training_oracle.json`：838×8 的私有元数据/GT 选择整图复述上界诊断。

本机复算命令：

```bash
PY=python3
$PY outputs/sft_followup_20260921/shortcut/verify_sources.py
$PY outputs/sft_followup_20260921/shortcut/analyze_shortcuts.py
$PY outputs/sft_followup_20260921/shortcut/aligned_training_oracle.py
```

`numpy` 是唯一额外依赖。不需要 scipy，不需要读图，不需要访问模型或服务。原始封存材料均只读。
