# SFT shortcut 离线复算包

本包复算 **2026-09-21 事后探索性诊断**：训练输出热点先验、保存地图的跨世界交换，以及可选的训练地图变换 oracle。它不调用模型，不训练，不联网，不改变原封存确认分析。唯一训练 seed 是 **20260920**；本脚本不需要随机排列。

## 使用

需要 Python 3 和 numpy。解压后在本目录运行：

```bash
python3 reproduce.py
```

默认复算训练热点和全部跨世界交换，检查每个目标世界的交换得分与原结果一致，输出 `reproduction.json`。依赖可通过 `python3 -m pip install -r requirements.txt` 安装；安装完成后的复算完全离线。

可选的较慢完整 oracle：

```bash
python3 reproduce.py --skip-priors --skip-swaps --oracle
```

只复核一个世界：

```bash
python3 reproduce.py --skip-priors --skip-swaps --oracle-world w202609200
```

`--oracle-world` 可重复；它使用全部 838 个候选训练地图和全部 8 种变换，仅缩小目标世界集合。可用 `--data`、`--metadata`、`--expected`、`--provenance` 和 `--out` 指定文件位置。输入哈希必须匹配本包 provenance，因此其它版本的页面数据需提供对应的新来源映射。

## 文件与来源

- `data.json`：新报告页面数据的原样快照，含 128 世界 GT、5 组保存预测、状态和分数。
- `metadata.json`：路径脱敏且只保留必要字段的派生输入：838 个训练世界的 family、真实 start pose、room center/size、冻结监督最后 finish 地图；128 测试世界的 family/stratum、GT、真实 start pose 和 room center/size。无坐标舍入。测试 GT 与页面数据再次交叉检查。
- `provenance.json`：原始输入 SHA256 → 公开文件 SHA256 映射；每条公开记录的规范化哈希及相关原源文件哈希。原机器名、内部目录和 SSH 地址已移除。哈希映射说明派生关系，不能代替缺失的原始文件。
- `expected_results.json`：原事后分析中对应的结果及每世界交换/oracle 得分，仅用于复算校验，**不用于热点拟合或选择预测**。
- `verification.json`：本次用公开输入生成的验收结果；默认项目全部复算，oracle 抽查 `w202609200`、`w202609248`、`w202619200`、`w202619231` 共 4 个世界、26,816 次候选变换评分，最优得分与选中的地图/变换均逐项相同。没有重新跑全部 858,112 次 oracle。
- `SHA256SUMS.json`：本包普通文件的字节校验和。

**本包不是全部原始实验材料**：不含 RGB、分割图、原始模型请求/响应、全部训练对话、模型权重或封存协议全集；不能重放模型推理，也不能仅凭本包重新审计图像泄漏或真实模型干预。发布数据是原证据的精简派生副本，原封存材料未改动。

## 算法与信息前提

所有数值使用父世界对象 F1：类别一致、距离 ≤0.75m、最大基数一一匹配，未完成预测为空图计零。128 世界等权，等价普通/物理遮挡权重 0.75/0.25。脚本先独立复核全部 640 状态在 0.75m/0.25m 的 1,280 项保存 F1。所有坐标为初始相机右/前方向的米制坐标。

1. **训练热点无图对照。** 仅从 838 个冻结监督 finish 地图拟合。每类在训练坐标的 0.25m 网格中选覆盖最多训练世界的 0.75m 热点，按命中率排序，仅在训练输出上选择预测类别数。固定全局地图测试均值 **0.0158471**。这是每类只有一个热点的受限基线，低分不能排除复杂先验。family 条件版本使用测试私有 family 标签，因此是额外信息 oracle；坐标替换版本保留了模型已看图得到的类别/数量，也不能称无图基线。
2. **离线跨世界地图交换。** 穷举异世界有序对；先在每个 target 内平均符合限制的 donor，再平均 128 target。全体/同层/同层同家族分别为 16,256/10,112/2,048 对。新模型 e2e 原坐标交换均值 **0.0087435**。房间归一化交换先用**真实私有姿态**还原房间坐标，按**真实房间尺寸**缩放，再转换目标相机坐标；同层同家族均值 **0.0219208**。该版本有模型原任务未获提供的信息。
3. **训练地图变换 oracle。** 对每个目标，试遍 838 训练地图 × 8 D4 旋转/镜像；使用**私有真实姿态/尺寸**作房间归一化，并由**测试 GT 选择最优地图与变换**。原完整均值 **0.4226111**，同家族限制 **0.3616653**。这是故意给检索器很大优势的整图复述诊断，绝不是可部署无图基线、模型实测性能或记忆机制证据。

这些都是**保存输出的离线评分操作**，不等于删图、错图、图像置换或工具移除后的模型实验。它们削弱某些简单 shortcut，不能证明真实 RGB 依赖、自适应探索、复杂先验缺失或未见资产泛化。分位数为描述性分布摘要，不是新确认性置信区间。
